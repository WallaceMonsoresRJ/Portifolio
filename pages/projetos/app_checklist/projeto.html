Sobre o projeto

Acompanhar rotinas em diferentes lojas exige organizar responsáveis, turnos e registros de execução. O App Checklist reúne essas informações em um sistema com painel administrativo responsivo.

Tecnologias utilizadas

  • React
  • TypeScript
  • NestJS
  • Prisma
  • PostgreSQL
  • Supabase
